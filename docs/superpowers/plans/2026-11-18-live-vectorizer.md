# LayerFit (LIVE-style photo vectoriser) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS app that fits flat-coloured closed Bézier shapes to a photo with LIVE's layer-wise method on the GPU, and shows every level of compression on a slider, in Re-fit and Prefix modes.

**Architecture:** A UI-free core framework (`LayerFitCore`) holds the shape model, a differentiable soft rasteriser written as MLX array operations, the loss, a small Adam, CPU-side seed placement, and the stage loop. A command-line tool and a SwiftUI app are thin layers over it. Results are always drawn from vectors with Core Graphics; the soft raster is used only for fitting.

**Tech Stack:** Swift 6.4, SwiftUI, Core Graphics / ImageIO, MLX Swift 0.33.0, XCTest, xcodegen, xcodebuild.

**Spec:** `docs/superpowers/specs/2026-11-18-live-vectorizer-design.md`

## Global Constraints

- macOS on Apple Silicon only. Deployment target macOS 15.0.
- MLX Swift pinned to exactly `0.33.0` from `https://github.com/ml-explore/mlx-swift`.
- Build and test only through `xcodebuild` (MLX's Metal shaders are not built by `swift build`). The Xcode project is generated by `xcodegen generate` and is git-ignored.
- No hand-written gradients: every gradient comes from MLX `valueAndGrad`.
- A shape is one closed path of 4 cubic segments (12 control points) with one opaque RGB colour. Fill rule is even-odd everywhere: rasteriser, Core Graphics, SVG.
- Colours are sRGB 0…1; the loss is computed in sRGB.
- Coordinates are working-image pixels; pixel centres are at `(x + 0.5, y + 0.5)`.
- Displayed and exported pictures are hard-edged vectors, never the soft raster.
- `LayerFitCore` imports no SwiftUI or AppKit.
- One deviation from the spec: Adam is a ~20-line struct on `MLXArray` rather than `MLXOptimizers.Adam`, because the library's optimiser is built around `MLXNN.Module` and we need per-parameter learning rates and a frozen subset. Autodiff is still MLX's.
- If an MLX function name below differs in 0.33.0, check the package source under `~/Library/Developer/Xcode/DerivedData/*/SourcePackages/checkouts/mlx-swift` and use the equivalent.

## Review Focus

1. **Photos that are rotated by EXIF, in Display P3, or have transparency** — expected: upright, colours converted to sRGB, transparency over white; an unreadable file gives an error message, not a crash. (Task 6)
2. **Shapes that collapse during optimisation** (all points coincide, zero-length edges) — expected: finite image and finite gradients, never NaN. (Task 3)
3. **A photo that is one flat colour, or already fitted perfectly** — expected: fitting finishes, shapes are still placed by the fallback, no NaN. (Task 5)
4. **Tiny or extreme-aspect images** (smaller than the working size, 1 px wide) — expected: no upscaling, no crash, at least 1 px per side. (Task 6)
5. **Interrupting**: Cancel mid-stage, Start again, switch mode, or open a new photo while fitting — expected: the old run stops, its late progress is ignored, finished levels are kept on Cancel and discarded on a new photo. (Task 8)

### Task 3: Differentiable rasteriser

**Files:** Create `Sources/LayerFitCore/Rasterizer.swift`, `Tests/LayerFitCoreTests/RasterizerTests.swift`

**Interfaces:**
- Consumes: `bezierBasis`.
- Produces:

```swift
public struct Rasterizer {
    public init(width: Int, height: Int, samplesPerSegment: Int = 8, softness: Float = 1.0, chunk: Int = 32)
    /// points [P,12,2], colors [P,3], background [3]. P may be 0.
    /// image [H,W,3]; boundaryDistance [H,W] = min over shapes of unsigned edge distance,
    /// with gradient stopped; all 1e6 when P == 0.
    public func render(points: MLXArray, colors: MLXArray, background: MLXArray)
        -> (image: MLXArray, boundaryDistance: MLXArray)
}
```

Algorithm (the signature does not determine it):

1. `poly = matmul(basis, points)` → `[P, E, 2]`, `E = 4 * samplesPerSegment`; edge k is `a = poly[k]`, `b = poly[(k+1) % E]`.
2. For pixel centre `p`, per edge: `t = clip(dot(p−a, b−a) / (|b−a|² + 1e-8), 0, 1)`, `d = sqrt(|p − a − t(b−a)|² + 1e-8)`. Unsigned distance `u = min over edges`.
3. Inside test, even-odd: an edge crosses when `(a.y > p.y) != (b.y > p.y)` and `p.x < a.x + (p.y − a.y) / (b.y − a.y) * (b.x − a.x)`; guard the division with `which` so non-crossing edges contribute 0 and never NaN. `inside = (crossings % 2 == 1)`. Wrap in `stopGradient`.
4. `alpha = sigmoid((inside ? u : −u) / softness)`.
5. Composite shapes in order: `C = C * (1 − alpha) + color * alpha`, starting from background.
6. Process shapes in groups of `chunk` to bound the `[H, W, chunk, E]` intermediates.

### Task 4: Loss and Adam

**Files:** Create `Sources/LayerFitCore/Loss.swift`, `Sources/LayerFitCore/Adam.swift`, `Tests/LayerFitCoreTests/LossTests.swift`, `Tests/LayerFitCoreTests/AdamTests.swift`

**Interfaces — Produces:**

```swift
public struct LossConfig: Sendable {
    public var boundaryReach: Float = 10   // px at 256 working size; scale by workingSize / 256
    public var floorWeight: Float = 0.2
    public var xingWeight: Float = 0.01
}
/// image, target [H,W,3]; boundaryDistance [H,W]; points [P,12,2] (all shapes that can move).
public func fitLoss(image: MLXArray, target: MLXArray, boundaryDistance: MLXArray,
                    points: MLXArray, config: LossConfig) -> MLXArray     // scalar
public func xingLoss(points: MLXArray) -> MLXArray                        // scalar, mean over segments
public func plainMSE(image: MLXArray, target: MLXArray) -> MLXArray       // scalar

public struct Adam {
    public init(learningRates: [Float], beta1: Float = 0.9, beta2: Float = 0.999, eps: Float = 1e-8)
    public mutating func step(parameters: [MLXArray], gradients: [MLXArray]) -> [MLXArray]
}
```

Definitions:

- `se` = per-pixel squared error summed over channels.
- `w = stopGradient(maximum(0, 1 − boundaryDistance / boundaryReach))`.
- `fitLoss = sum(w * se) / (sum(w) + 1e-6) + floorWeight * mean(se) + xingWeight * xingLoss(points)`. With `P == 0` the Xing term is 0.
- Xing loss, per segment with control points A, B, C, D: `D1 = stopGradient(cross(B−A, C−B) > 0 ? 1 : 0)`, `sinα = cross(B−A, D−C) / (|B−A| * |D−C| + 1e-6)`, `loss = D1 * relu(−sinα) + (1 − D1) * relu(sinα)`.

### Task 5: Seeds and the stage loop

**Interfaces:**
- Consumes: `Rasterizer`, `fitLoss`, `plainMSE`, `Adam`, `Shape.circle`, `stageSchedule`.
- Produces:

```swift
public struct TargetImage: Sendable {
    public var width: Int, height: Int
    public var pixels: [Float]            // row-major RGB, sRGB 0…1, count == width*height*3
}
public struct Seed: Equatable, Sendable { public var center: SIMD2<Float>; public var radius: Float; public var color: RGB }
/// `current` has the same layout as target.pixels.
public func findSeeds(target: TargetImage, current: [Float], count: Int,
                      errorThreshold: Float = 0.1, colorLevels: Int = 4) -> [Seed]

public struct FitProgress: Sendable {
    public var stage: Int, stageCount: Int   // stage is 1-based
    public var step: Int, stepCount: Int
    public var picture: Picture
    public var finishedLevel: Level?         // non-nil exactly once per stage, and once for level 0
}
public struct Fitter {
    public init(target: TargetImage, settings: FitSettings, loss: LossConfig = .init())
    /// Blocking. Returns the levels finished so far (level 0 first) when done or cancelled.
    public func run(progress: (FitProgress) -> Void, isCancelled: () -> Bool) -> [Level]
}
```

Seed placement (`findSeeds`):

1. Per-pixel error = Euclidean RGB distance between `current` and target.
2. Candidate pixels: error > `errorThreshold`. Label each with the target colour quantised to `colorLevels` per channel.
3. 4-connected components of equal label among candidates; take the largest.
4. Centre = the component pixel with the greatest distance to a non-component pixel (two-pass chamfer distance transform); `radius = clamp(thatDistance, 2, max(width, height) / 16)`; colour = target colour at the centre.
5. Remove the chosen component from the candidates and repeat until `count` seeds.
6. When candidates run out: seed at the highest-error pixel not within 4 px of an existing seed, radius 2.

Stage loop (`Fitter.run`):

- Level 0: no shapes, background = target mean colour. Report it with `finishedLevel`.
- Per stage: render the current picture; `findSeeds` for this stage's count; append the circles.
- Parameters and learning rates (new `Adam` every stage):
  - `.refit`: all points (lr `1.0 * workingSize / 256`), all colours (0.01), background (0.01).
  - `.prefix`: only this stage's points and colours, same rates. Earlier shapes and background are passed to the rasteriser as constants.
- Each step: `valueAndGrad` of `fitLoss` over the movable parameters; `Adam.step`; clamp colours to 0…1; `eval`. `points` passed to `fitLoss` are the movable ones.
- Report progress every 10 steps (no `finishedLevel`) and check `isCancelled` every step.
- End of stage: snapshot to `Picture`, `mse = plainMSE`, report with `finishedLevel`.
- Cancelled mid-stage: return without snapshotting the unfinished stage.

Bad arguments or an unreadable image print a one-line error to stderr and exit 1.

**Interfaces — Consumes:** `FitModel`, `draw(_:in:size:)`.

Layout is the spec's window sketch. Decisions it leaves open:

- Controls: `Open…` (`.fileImporter`, images), pickers Shapes `32/64/128/256`, Size `128/256/384/512`, a Steps field (10…1000), segmented `Levels` control `Re-fit | Prefix`, `Start`.
- Shapes, Size and Steps are disabled while fitting. The Levels toggle stays enabled: it switches which result is shown; it takes effect for fitting on the next Start.
- `PictureView` is a SwiftUI `Canvas` calling `draw` through `withCGContext`, aspect-fit and centred. With no photo it shows "Drop a photo here"; the whole window accepts file drops.
- Slider: integer stops `0…levels.count−1`, disabled with fewer than 2 levels; label "8 of 14" (stop of stage count). Left/right arrow keys step it.
- `Hold: original` shows the source photo while the mouse button is down.
- Status line: "Fitting stage 11 of 14" with a progress bar and `Cancel` while fitting; "Done" / "Cancelled" otherwise. `errorMessage` is shown in an alert.
- `Export SVG` (`.fileExporter`), disabled with no levels.
- Minimum window size 720×560.

- [ ] **Step 1: Implement the views.**
- [ ] **Step 2: Build:** `xcodebuild build -scheme LayerFit -destination 'platform=macOS' -derivedDataPath .build/dd`. Expected: `BUILD SUCCEEDED`.
- [ ] **Step 3: Launch** `.build/dd/Build/Products/Debug/LayerFit.app` and check by hand, taking a screenshot at each point:
  1. Empty window shows the drop hint.
  2. Open a desktop picture; Start with Shapes 32; the picture updates while fitting and the window stays responsive (resize it during the fit).
  3. Slider at first, middle and last stop: edges are hard at full window size; caption changes.
  4. Fit Prefix mode; toggling Levels swaps the picture and keeps the stop.
  5. Hold: original shows the photo; arrow keys move the slider.
  6. Cancel mid-fit keeps the finished stops.
  7. Export SVG; open the file in a browser; it matches the window.
- [ ] **Step 4: Commit** `feat: LayerFit window`.
